# Land Tokenization Platform

Production-grade land tokenization and leasing platform using:

- Hyperledger Fabric 2.5.12 LTS
- Golang 1.20
- FastAPI
- Streamlit
- PostgreSQL
- CouchDB

## Features

- Property tokenization
- Fractional ownership
- Marketplace
- Escrow-based leasing
- RBAC
- JWT authentication
- Fabric Gateway integration
- IPFS/S3 support
- Dockerized deployment
